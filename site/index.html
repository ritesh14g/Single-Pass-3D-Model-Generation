Step 2 of 4 · runs before any processing time is spent

Input check

Before reconstructing anything, the system reads the file itself, the position log and the agreement between the two. Each check reports a measured value, what it means, and how to fix it when it is worth fixing. A blocking result stops the run here rather than after twenty minutes of computation.
